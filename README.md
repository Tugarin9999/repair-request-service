# Сервис приёма заявок на ремонт

Веб-приложение для небольшой ремонтной мастерской. Клиент оставляет заявку, получает номер и по этому номеру в любой момент видит текущий статус. Мастерская перестаёт отвечать на звонки «когда будет готово».

Стек: Python + Streamlit + SQLite. Ничего больше не нужно — ни сервера приложений, ни СУБД.

## Возможности

**Клиент**

- оставляет заявку: устройство, неисправность, контакт;
- получает номер заявки вида `2026-0001`;
- проверяет статус по номеру и читает комментарий мастера.

**Мастер** (за паролем)

- видит список заявок с контактами клиентов;
- фильтрует список по статусу;
- меняет статус и пишет комментарий, который видит клиент.

Статусы идут строго по конвейеру, порядок задан требованиями:

```
принято → диагностика → ремонт → готово → выдано
```

## Требования

- Python 3.11 или новее (код использует `StrEnum`). Проверено на 3.14.2.
- Windows, macOS или Linux.

## Установка

```
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

`requirements.txt` содержит только `streamlit`, `requirements-dev.txt` подтягивает его и добавляет `pytest`.

## Запуск

Пароль мастера обязателен. Без него экран мастера закрыт — пароля по умолчанию нет.

В PowerShell:

```
$env:REPAIR_SERVICE_MASTER_PASSWORD = "мастер-2026"
.venv\Scripts\python.exe -m streamlit run app.py
```

В cmd:

```
set REPAIR_SERVICE_MASTER_PASSWORD=master-2026
.venv\Scripts\python.exe -m streamlit run app.py
```

Пароль может быть любым, в том числе кириллическим, — сравнение идёт по байтам UTF-8. Но cmd с кириллицей в переменных окружения иногда портит значение из-за кодовой страницы консоли, поэтому для cmd надёжнее латиница.

Приложение откроется на `http://localhost:8501`.

## Тесты

```
.venv\Scripts\python.exe -m pytest -q
```

40 проверок: слой данных, пароль и оба экрана. Экраны проверяются через `streamlit.testing.v1.AppTest` — это прогон настоящего приложения без браузера.

Слой данных и пароль запускаются вообще без зависимостей, если venv нет:

```
python tests\test_data.py
python tests\test_auth.py
```

## Данные

Всё лежит в `data/requests.db`, в git не отслеживается. Путь можно переопределить переменной `REPAIR_SERVICE_DATA_DIR` — это нужно тестам, чтобы каждая проверка работала на своей временной базе.

## Что стоит знать

**Контакт клиента не может попасть на клиентский экран.** Это не договорённость, а устройство типов: клиентская выборка отдаёт `RequestStatusView`, где полей `contact` и `fault` физически нет. Клиент видит только номер, статус, комментарий и дату.

**Пароль мастера — не настоящая аутентификация.** У Streamlit нет серверного слоя сессий, поэтому пароль закрывает интерфейс от того, кто просто открыл приложение в общей сети, но не защищает файл базы и не защищает трафик: по обычному HTTP пароль уходит открытым текстом. Для работы внутри локальной сети этого достаточно, чтобы выставить наружу — нет.

**Миграций нет.** Схема создаётся идемпотентно при старте. Если менять `statuses.py`, существующая база сама не обновится — вручную или с удалением `data/requests.db`.

**Номер заявки последовательный** и потому его можно перебирать: `2026-0001`, `2026-0002` и так далее. Поэтому клиентский экран показывает только статус и комментарий, а не устройство и описание неисправности.

**Один общий пароль мастерской, без логинов.** Этого хватает, пока мастер один. Если мастеров станет несколько, понадобится отдельная история входа.

## Если не запускается

**Первый запуск спрашивает email в консоли и блокируется.** Это особенность Streamlit. Отключается один раз в `%USERPROFILE%\.streamlit\config.toml`:

```toml
[server]
showEmailPrompt = false
```

Файл обязательно **без BOM** — иначе парсер `toml` падает с «Found invalid character in key name». В PowerShell 5.1 `Set-Content -Encoding UTF8` BOM добавляет, поэтому надёжнее:

```powershell
[System.IO.File]::WriteAllText("$env:USERPROFILE\.streamlit\config.toml", "[server]`r`nshowEmailPrompt = false`r`n", (New-Object System.Text.UTF8Encoding($false)))
```

**В окне терминала появляется `UnicodeEncodeError` на символе `⚠`.** Это не приложение: так ругается собственная фича Streamlit «one-click skills install» — симлинки на этой машине не поддерживаются. На работу не влияет.

**В консоли вместо русского текста мусор.** Это кодовая страница консоли, а не испорченные файлы. Чтобы прочитать вывод:

```
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```
